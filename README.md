\# Hệ thống quản lý nhân sự trên nền tảng đám mây



\## Thông tin sinh viên



\- Họ tên: QUÁCH THÁI TIỀN

\- MSSV: 237060

\- Lớp: DH23TIN10



\## Mô tả hệ thống



Hệ thống quản lý nhân sự cho phép quản lý thông tin nhân viên,

bao gồm xem danh sách, thêm, tìm kiếm, cập nhật và xóa nhân viên.



Dữ liệu được lưu trữ trên MongoDB Atlas. Frontend React giao tiếp

với backend Node.js/Express thông qua REST API.



\## Công nghệ sử dụng



\- Frontend: React

\- Backend: Node.js, Express

\- Database: MongoDB Atlas

\- Container: Docker

\- Source Code: Git, GitHub

\- Deployment: Docker Hub, Render
